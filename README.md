Abstract

SmartCampus is an AI-powered campus issue management system designed to intelligently handle student complaints. It uses AI to classify issues, detect duplicate complaints, determine priority, and recommend the appropriate department. Features such as “I’m Also Affected,” SLA-based escalation, notifications, and analytics help reduce duplicate reports and improve issue resolution. The project follows Agile, DevOps, and MLOps practices to develop a scalable and efficient solution.

Setup and Execution Instructions

Install Java JDK, Node.js, Python, MySQL, Git, and VS Code/IntelliJ IDEA.
Clone the project repository from GitHub.
Configure the MySQL database and update the backend database credentials.
Start the Spring Boot backend.
Install frontend dependencies using npm install and start the React application.
Set up the Python environment and install the required AI/ML libraries.
Start the AI/ML service for complaint classification and duplicate detection.
Open the application in a web browser and log in as Student, Staff, or Admin.
Test complaint submission, AI classification, duplicate detection, prioritization, assignment, resolution, and feedback features.
Use GitHub Actions, Docker, SonarQube, and OWASP ZAP for CI/CD, containerization, code-quality analysis, and security testing during later development phases.
